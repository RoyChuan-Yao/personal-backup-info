隱私權政策

Personal Backup · 更新日期：2026-10-10

適用範圍

本政策說明擁有者個人備份流程如何存取、使用、儲存及分享 Google 使用者資料。本工具供擁有者本人使用，未提供第三方帳號註冊或代管備份服務。

存取的資料與權限

rclone 使用 Google OAuth 憑證存取擁有者授權的 Google Drive。備份流程使用的資料包括備份檔案內容、名稱、大小、校驗資訊及所在資料夾。實際權限以 Google 授權畫面為準；若授予較廣的 Drive 權限，該憑證技術上也可能存取授權範圍內的其他檔案。此備份流程的日常操作限於設定的備份資料夾。

使用目的

這些資料用於建立個人異機備份、確認上傳完整性、檢查可用儲存空間，以及由擁有者下載與還原備份。Google API 資料不會用於廣告、出售、建立使用者行為画像或訓練人工智慧模型。

儲存與保護

應用與系統備份在上傳前以 age 加密，Google Drive 保存的是加密檔案。備份解密金鑰由擁有者另行保管。OAuth 授權憑證由 rclone 儲存在擁有者管理的主機或設定環境，以受限制的檔案權限保護；若包含在完整系統備份內，也受到該備份的 age 加密保護。

保存與刪除

雲端備份目前由擁有者手動管理保存期限；停止排程或撤銷授權不會自動刪除既有備份。擁有者可透過自己的 Google Drive 刪除備份並依需要清空垃圾桶，也可在自架環境刪除本機備份及 rclone 設定中的授權憑證。

服務提供者與分享

Google 提供帳號授權與 Google Drive 儲存服務。備份檔案的分享權限由擁有者管理；本備份流程不主動授權其他使用者存取檔案，也不出售 Google 使用者資料。本公開說明頁由 GitHub Pages 託管，託管平台可能依其政策處理網站存取日誌；說明頁本身沒有登入、表單、追蹤程式或資料上傳功能。

撤銷授權

擁有者可以在 Google 帳戶的「第三方應用程式與服務連結」中移除此 OAuth 應用的授權。移除授權後，後續雲端備份與檔案存取會停止；已存在於 Drive 的備份需要另行刪除。

Google 資料使用

本工具使用 Google API 所接收的資訊時，遵守 Google API Services User Data Policy，包括其中的 Limited Use 要求。
